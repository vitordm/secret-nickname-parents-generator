# Gerador de Apelidos

Projeto React + TypeScript + Vite para um jogo interativo de revelação.

## Como rodar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Testes

```bash
npm test
```

## Dados dos participantes

Os participantes vivem em `src/data/participants.json`.
Para adicionar alguém novo:

1. Adicione o registro no JSON.
2. Inclua a imagem em `public/participants/`.
3. Inclua a imagem de ajuda em `public/generated/`.
